# .NET Skills Hub — Website

Built with [Astro](https://astro.build).

## Commands

| Command | Action |
|---------|--------|
| `npm run dev` | Start dev server at `localhost:4321` |
| `npm run build` | Build for production to `./dist` |
| `npm run preview` | Preview production build locally |
| `npm run astro` | Run Astro CLI commands |

## Project Structure

```
site/
├── src/
│   ├── layouts/
│   │   └── Layout.astro        # Base layout with nav & footer
│   ├── components/
│   │   ├── SearchBar.astro     # Search component
│   │   ├── CategoryCard.astro  # Category display card
│   │   └── SkillCard.astro     # Skill display card
│   ├── pages/
│   │   ├── index.astro         # Homepage
│   │   ├── skills/[id].astro   # Dynamic skill detail pages
│   │   └── categories/[id].astro # Dynamic category pages
│   ├── styles/
│   │   └── global.css          # Dark theme with .NET purple
│   └── data/
│       └── skills.json         # Generated by aggregate script
├── public/                     # Static assets
├── astro.config.mjs            # Astro configuration
├── tsconfig.json               # TypeScript configuration
└── package.json                # Dependencies & scripts
```

## Development

```bash
# Install dependencies
npm install

# Run aggregation script (from root)
cd .. && npm run aggregate && cd site

# Start dev server
npm run dev
```

## Build

```bash
# Build for production
npm run build

# Output: ./dist
```

The site is automatically deployed to GitHub Pages via GitHub Actions.
